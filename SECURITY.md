# Security

Halftone runs entirely in the browser: images are processed on the user's own device and nothing
is sent to a server. The studio stores the last settings and the last opened image in that
browser's local storage only.

## Reporting a vulnerability

Please don't open a public issue. Email **hello@interfaz.studio** with a description and, if
possible, steps to reproduce. We'll reply within a few working days and credit you in the fix
unless you'd rather we didn't.

## Supported versions

Fixes go into the latest release of `@interfaz/halftone` and into halftone.interfaz.studio.
